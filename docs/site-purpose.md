# 这里要呈现什么

核心目标：呈现我的趣味。

一个具体问题的思考和实验可以有趣，一个具体的音乐作品也可以有趣。内容以具体对象为中心，媒介服务于它。

## 收录判断

- 具体是什么？读者能读到、听到、看到或尝试什么？
- 我为什么选择它？摘要应写出具体的吸引之处。
- 这一页是否有独立存在的价值？避免重复仓库说明与为更新而更新。

不要求每件内容都有成果或结论；尚未解决的问题也可以留下。

## 呈现方式

首页统一展示最多六条精选，不按代码、文章、音乐、视频分割版面。归档按时间容纳所有公开内容。分类只辅助说明内容形式。

继续保留纸面风格、狐狸、中英界面与明暗模式。后台、留言、统计等功能不作为默认建设目标。

## 尚未决定

音乐可先用真实来源链接发布，自有或已获授权的音频可提供站内播放。是否以原创为主、是否跨页连续播放，等具体作品与体验明确后再决定。
